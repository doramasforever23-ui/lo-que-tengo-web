# Guía de commits (mínimo 15)

Haz un commit cuando termines cada parte, con tu propio trabajo y entendiendo lo que subes. Una secuencia posible:

1. `git init` y primer commit: README y .gitignore
2. Agregar `backend/alimentos.csv` (base de datos de alimentos)
3. Agregar `backend/nucleo.py` (cálculo de metas)
4. Agregar el armado de menús en `nucleo.py`
5. Agregar `backend/main.py` con registro y login
6. Agregar verificación por código
7. Agregar perfil, nevera y menú a la API
8. Agregar marcar comidas y progreso
9. Agregar `frontend/estilos.css`, `config.js` y `comun.js`
10. Agregar `frontend/auth.html` (React)
11. Agregar `frontend/app.html` (nevera y menú)
12. Agregar `frontend/index.html` (marca y home)
13. Agregar catálogo y pedidos (API y página)
14. Agregar contacto
15. Agregar panel de administrador
16. Agregar el asistente con IA
17. Agregar `.github/workflows/pages.yml` y publicar

Comandos de cada commit:
```
git add .
git commit -m "Mensaje claro de lo que agregaste"
git push
```
